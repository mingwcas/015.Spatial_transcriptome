# Method: 3D Rendering and Visualization

## 原文（Methods）
> Three-dimensional visualizations were generated by downscaling and mapping the spatial coordinates of segmented cell centroids onto 300x300 images along the xy-axes, using data from sections 10, 16, 22 and 28 along the z-axis. From these, 300x300x100 voxel data was constructed by interpolating 25 intermediate sections between each of the four sections using weighted Convolutional Wasserstein barycenters. Voxel data were exported as TIFF ﬁles and visualized using ParaView v5.10 as surface or volumetric representations.

## 解读

### 意义
将3D空间转录组数据和分析结果渲染为可视化3D图像，直观展示niche空间关系、基因表达密度和通讯网络。

### 输入
- sections 10, 16, 22, 28的细胞空间坐标
- 3D niche分配、基因表达、配体活性评分

### 输出
- 300×300×100体素数据（TIFF）
- ParaView 3D渲染图像

### 核心步骤
1. 将细胞质心坐标映射到300×300的xy平面图像
2. 使用加权Convolutional Wasserstein barycenters在4张切片间插值25个中间层
3. 构建300×300×100体素数据
4. 导出为TIFF文件
5. 使用ParaView v5.10进行表面或体积渲染

### 关键参数（本文设置）
| 参数 | 值 | 含义 |
|------|-----|------|
| 体素分辨率 | 300×300×100 | xy平面300×300，z轴100层 |
| 插值方法 | Convolutional Wasserstein barycenters | 最优传输插值 |
| 中间层插值 | 25层/间隔 | 每对切片间插值25层 |
| 可视化工具 | ParaView v5.10 | 科学可视化软件 |
| 使用切片 | sections 10, 16, 22, 28 | 用于3D渲染的4张CosMx切片 |

## 名词/参数/指标
| 名词 | 定义 |
|------|------|
| 体素 | 3D像素（Voxel），三维空间中的最小数据单元 |
| Wasserstein barycenter | 最优传输理论中的加权平均，用于平滑插值 |
| ParaView | 开源科学数据可视化和分析软件 |
| 表面渲染 | 以等值面展示3D结构 |
| 体积渲染 | 以半透明体展示3D密度分布 |

## 复现
- ParaView v5.10: Ahrens et al., 2005 (Visualization Handbook)
- https://www.paraview.org/
- 代码: https://github.com/rajewsky-lab/3D_lung

## 生物学意义
3D渲染使复杂的多细胞niche空间关系变得直观可理解。通过体积渲染展示了niche的空间嵌套关系（如肿瘤表面包裹肿瘤核心、树突状细胞和巨噬细胞niche嵌入肿瘤表面），以及基因表达和通讯活性的3D密度分布（如EMT niche中整合素信号的局部富集）。
