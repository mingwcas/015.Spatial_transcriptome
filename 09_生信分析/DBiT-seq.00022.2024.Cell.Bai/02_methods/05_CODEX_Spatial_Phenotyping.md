# Method: CODEX Spatial Phenotyping

## 原文（Methods）
> CODEX spatial phenotyping using PhenoCycler-Fusion. High-plex spatial cell typing on an adjacent tissue section using the co-detection by indexing (CODEX) assay.

## 解读

### 意义
使用CODEX技术对相邻组织切片进行高plex空间细胞分型，验证Patho-DBiT结果

### 输入
- 相邻组织切片
- DNA偶联抗体
- 荧光标记

### 输出
- 蛋白质表达空间图谱
- 细胞类型空间分布

### 核心步骤
1. 组织切片准备
2. 抗体孵育
3. DNA偶联抗体标记
4. 荧光成像
5. 图像处理和分析

### 关键参数（本文设置）
| 参数 | 值 | 含义 |
|------|-----|------|
| 抗体数量 | 高plex | 多重蛋白质标记 |
| 成像系统 | PhenoCycler-Fusion | 高分辨率成像 |
| 标记类型 | DNA偶联抗体 | 可扩展的标记系统 |

## 名词/参数/指标
| 名词 | 定义 |
|------|------|
| CODEX | 共检测索引技术 |
| PhenoCycler-Fusion | CODEX成像系统 |
| 空间细胞分型 | 在组织中识别细胞类型 |

## 生物学意义
该方法提供了蛋白质水平的空间信息，与转录组数据相互验证，增强了研究结果的可靠性。
