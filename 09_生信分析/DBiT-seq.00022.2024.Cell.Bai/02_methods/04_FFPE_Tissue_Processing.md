# Method: FFPE Tissue Processing

## 原文（Methods）
> Tissue deparaffinization and decrosslinking. Heat-induced crosslink reversal enables detection of RNA molecules in FFPE tissues.

## 解读

### 意义
处理FFPE组织样本，逆转福尔马林固定导致的RNA交联和降解

### 输入
- FFPE组织切片
- 二甲苯
- 热处理缓冲液

### 输出
- 脱蜡组织
- 去交联RNA

### 核心步骤
1. 二甲苯脱蜡
2. 乙醇梯度复水
3. 热诱导交联逆转
4. RNA释放和恢复

### 关键参数（本文设置）
| 参数 | 值 | 含义 |
|------|-----|------|
| 脱蜡试剂 | 二甲苯 | 溶解石蜡 |
| 热处理温度 | 优化温度 | 逆转交联 |
| 处理时间 | 优化时间 | 确保充分去交联 |

## 名词/参数/指标
| 名词 | 定义 |
|------|------|
| FFPE | 福尔马林固定石蜡包埋 |
| 交联 | 福尔马林导致的分子间连接 |
| 去交联 | 逆转福尔马林固定效应 |

## 生物学意义
该方法使长期存档的临床FFPE样本能够用于转录组学研究，为回顾性研究提供了宝贵资源。
