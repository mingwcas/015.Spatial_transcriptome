# Fig. 8 — Open-ST library profiles before and after size selection

## Caption（原文）
> (A) Library profile of a metastatic lymph node library before size selection.
> (B) As (A), but after gel-based size selection. BioAnalyzer traces visualized with 2100 Expert software version B.02.10.SI764 (Agilent) are shown. Total cDNA amount and average size of the region of interest are indicated in the table below.

## Panel-by-Panel 解读

### Panel A — Before size selection
**结论**：展示了大小选择前的文库分布，可见小片段干扰峰。

**关键数据**：在 ~185 bp 和 ~226 bp 处有假峰，主峰在 ~500-600 bp。

### Panel B — After size selection
**结论**：展示了大小选择后的文库分布，假峰被去除。

**关键数据**：大小选择后 250 bp 以下的片段完全去除，文库分布平滑。

## 总体结论
Fig. 8 展示了大小选择对 Open-ST 文库质量的影响。大小选择前，文库含有引物二聚体等小片段干扰（~185 bp 和 ~226 bp）。通过 BluePippin 凝胶电泳大小选择（350-1100 bp），这些干扰被有效去除，得到平滑的文库分布。大小选择后的文库适合测序，预期产量为大小选择前的 50-80%。
