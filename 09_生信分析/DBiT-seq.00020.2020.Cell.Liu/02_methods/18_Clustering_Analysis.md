# Method: Clustering Analysis

## 原文（Methods）
> Spatially variable genes were identified by SpatialDE (Svensson et al., 2018). The resulting list of differentially expressed genes was submitted to ToppGene (Chen et al., 2009) for GO and Pathway enrichment analysis. Spatially variable genes generated by SpatialDE were used to conduct the clustering analysis. Non-negative matrix factorization (NMF) was performed using the NNLM packages in R, after the raw expression values were log-transformed. We chose k of 11 for the mouse embryo DBiT-seq transcriptome data obtained at a 50 μm pixel size. For each pixel, the largest factor loading from NMF was used to assign cluster membership. NMF clustering of pixels was plotted by tSNE using the package ''Rtsne'' in R.

## 解读

### 意义
该方法通过识别空间变异基因并进行非负矩阵分解聚类，将像素分组以揭示组织内空间domain。

### 输入
- SCTransform标准化后的表达矩阵
- SpatialDE
- NNLM R包
- Rtsne R包

### 输出
- 空间变异基因列表
- NMF聚类结果（k=11）
- tSNE可视化

### 核心步骤
1. 使用SpatialDE识别空间变异基因
2. ToppGene进行GO和Pathway富集分析
3. 取空间变异基因进行后续聚类
4. 对数转换原始表达值
5. 使用NNLM包执行NMF，k=11（50μm像素数据）
6. 每个像素取最大因子载荷分配cluster membership
7. 使用Rtsne进行tSNE可视化

### 关键参数（本文设置）
| 参数 | 值 | 含义 |
|------|-----|------|
| 空间变异基因鉴定 | SpatialDE | 自动识别空间表达模式 |
| 聚类方法 | NMF (k=11) | 非负矩阵分解 |
| 可视化 | tSNE (Rtsne) | 二维降维展示 |
| NMF因子数 | k=11 | 50μm胚胎数据 |

## 名词/参数/指标
| 名词 | 定义 |
|------|------|
| SpatialDE | Spatial Differential Expression，识别空间变异基因的方法 |
| NMF | Non-negative Matrix Factorization，非负矩阵分解，聚类方法 |
| tSNE | t-distributed Stochastic Neighbor Embedding，流行的降维可视化方法 |
| ToppGene | 基因富集分析工具 |

## 复现
- 工具/代码/URL：SpatialDE (https://github.com/Teichlab/SpatialDE); NNLM R包; Rtsne R包
- 关键调用：NA

## 生物学意义
SpatialDE是专门为空间转录组开发的差异表达分析方法，能够自动识别具有空间表达模式的基因。NMF聚类将像素分组为具有相似转录组特征的spatial domains，k=11表示50μm数据识别出11个主要组织区域。tSNE可视化展示了像素在转录组空间的分布。
