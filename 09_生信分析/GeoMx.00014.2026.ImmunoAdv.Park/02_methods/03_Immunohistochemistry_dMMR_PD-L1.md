# Method: Immunohistochemistry for dMMR and PD-L1

## 原文（Methods）
> FFPE tissues were sectioned (4 μm), mounted on Superfrost Plus slides, and dried at 60°C. IHC for MLH1, PMS2, MSH2, and MSH6 was performed as previously reported, with loss of one or more proteins indicating dMMR. PD-L1 IHC was conducted on a Dako Autostainer Link 48 using the PD-L1 IHC 22C3 pharmDx Kit and EnVision FLEX detection. Combined positive score (CPS) was calculated for tumor and immune cells; CPS ≥1 was considered PD-L1-positive cells using IHC. The specimen was considered PD-L1-positive when CPS was ≥1.

## 解读

### 意义
通过免疫组化验证dMMR状态和PD-L1表达水平，为后续免疫治疗响应预测提供组织学依据。

### 输入
- FFPE组织切片（4 μm厚）
- Superfrost Plus载玻片
- PD-L1 IHC 22C3 pharmDx Kit（Dako）
- EnVision FLEX检测系统

### 输出
- dMMR状态判定（MLH1/PMS2/MSH2/MSH6表达缺失）
- PD-L1 CPS评分（CPS ≥1为阳性）

### 核心步骤
1. FFPE组织4 μm连续切片
2. Superfrost Plus载玻片贴片，60°C烤片
3. MLH1、PMS2、MSH2、MSH6免疫组化（dMMR确认）
4. 任一蛋白缺失即判定为dMMR
5. Dako Autostainer Link 48进行PD-L1免疫组化
6. PD-L1 IHC 22C3 pharmDx Kit + EnVision FLEX显色
7. 计算CPS（肿瘤细胞+阳性免疫细胞）/总肿瘤细胞数×100
8. CPS≥1判定为PD-L1阳性

### 关键参数（本文设置）
| 参数 | 值 | 含义 |
|------|-----|------|
| 切片厚度 | 4 μm | |
| 烤片温度 | 60°C | |
| dMMR判定 | 任一蛋白表达缺失 | MLH1/PMS2/MSH2/MSH6 |
| PD-L1检测平台 | Dako Autostainer Link 48 | |
| 抗体克隆号 | 22C3 | pharmDx Kit |
| CPS阳性阈值 | ≥1 | PD-L1阳性标准 |

## 名词/参数/指标
| 名词 | 定义 |
|------|------|
| FFPE | Formalin-Fixed Paraffin-Embedded，甲醛固定石蜡包埋 |
| dMMR | DNA错配修复缺陷 |
| CPS | Combined Positive Score，联合阳性评分 |
| PD-L1 | Programmed Death-Ligand 1，程序性死亡配体1 |

## 复现
- 商业平台：Dako Autostainer Link 48
- 商业试剂盒：PD-L1 IHC 22C3 pharmDx Kit

## 生物学意义
dMMR导致MSI-H和高肿瘤突变负荷，是免疫检查点抑制剂响应的预测因子。PD-L1 CPS是泛实体瘤免疫治疗响应的重要生物标志物。
